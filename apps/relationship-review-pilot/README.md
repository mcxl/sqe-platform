# Relationship Review Pilot

This is a read-only Next.js pilot for fictional relationship-review data.

## Run

1. Copy `.env.example` to `.env.local`.
2. Set `NEXT_PUBLIC_CONVEX_URL` to a pilot Convex deployment URL.
3. Run `npm install` and `npm run dev`.

The pilot has two public Convex queries and an internal seed function. It has no public mutation or data-import path.

Do not use client, personal, or confidential records. The included seed data is fictional.
