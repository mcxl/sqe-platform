# SQE Platform Context

SQE Platform supports controlled auditor review work.
It records evidence, relationships, assessments, and auditor decisions.

## Core Terms

An Engagement has a defined purpose, scope, authority, and review period.
An Audit Question asks about one control in an Engagement.
A Binding Obligation is a scoped requirement from an identified instrument.
A Risk is a safety risk that the Engagement examines.
A Control is a governance measure that manages a Risk.

An Evidence Item identifies its source, date or version, location, and freshness.
An Evidence Gap identifies missing, stale, unavailable, or inadequate evidence.
An Evidence Relationship can support, weaken, or contradict an Audit Question.

A Proposed Relationship is a versioned link between two records.
An Auditor Decision approves, rejects, or requests changes to a current version.
An Approved Relationship needs an approval for the same current version.

MATE means Mandate, Accountability, Trigger, and Escalation.
A MATE Assessment checks control design. It does not decide effectiveness.
An Approved Conclusion records the auditor's implementation or effectiveness decision.

## Control Rules

The platform does not approve professional decisions automatically.
Approved records remain immutable. A correction creates a new version.
Open material gaps and unresolved contradictions block substantive conclusions.
G0 blocks client data until an approved boundary permits it.
