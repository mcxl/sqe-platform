# Engagement Setup Workflow

## Status

Approved for fictional implementation. G0 blocks client data.

## Purpose

The accountable auditor creates the Engagement that holds scope, evidence, and decisions.

## Required Inputs

- Authenticated auditor session.
- Engagement title and unique reference.
- Purpose, authority, scope, exclusions, review period, and data classification.

## Actions

1. Create a draft Engagement.
2. Record scope, exclusions, and authority.
3. Apply G0 to the stated data classification.
4. The auditor approves activation.
5. Show the active Engagement beside capture actions.

## Controls

The auditor controls activation. A scope change after activation creates a new version.
