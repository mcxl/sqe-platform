# MATE Assessment Workflow

## Status

Approved for fictional implementation. G0 blocks client data.

## Purpose

MATE checks a Control's Mandate, Accountability, Trigger, and Escalation.
It does not assess implementation or effectiveness.

## Required Inputs

- Authenticated auditor session and active Engagement.
- Approved Binding Obligation, Risk, and Accountable Role links.
- Current proposal and reviewed evidence for each MATE dimension.

## Actions

1. Show the approved planning links.
2. Review Mandate, Accountability, Trigger, then Escalation.
3. Record one auditor decision for each current proposal.
4. Block completion for missing evidence or unresolved contradictions.
5. Apply the existing deterministic rating after four approvals.

## Controls

The auditor cannot edit the calculated rating.
An approved MATE Assessment is immutable and does not create a conclusion.
