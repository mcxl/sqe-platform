# Conclusion Review Workflow

## Status

Approved for fictional implementation. G0 blocks client data.

## Purpose

The auditor approves separate implementation and effectiveness conclusions.

## Required Inputs

- Authenticated auditor session and active Engagement.
- Accepted Planning Trace and Approved MATE Assessment.
- Approved main, implementation, and effectiveness Audit Questions.
- Current evidence matrices, gaps, contradictions, and conclusion proposals.

## Actions

1. Show the planning trace and MATE rating.
2. Review the implementation proposal and evidence matrix.
3. Record a decision with a review note and sufficiency decision.
4. Review the separate effectiveness proposal.
5. Create the accepted record after both current proposals are approved.

## Controls

Open material gaps and unresolved contradictions block substantive conclusions.
`NOT_DETERMINED` records an evidence limitation. It is not a pass or failure.
