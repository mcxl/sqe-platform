# Documentation Control

## Purpose

This repository stores controlled technical documentation for SQE Platform.

## Locations

- `docs/specs/` stores approved technical specifications.
- `docs/adr/` stores accepted architecture decisions.
- `docs/agents/` stores agent controls.
- `workflows/` stores approved workflow specifications.
- `docs/diagrams/controlled/mermaid/` stores editable diagram source.

## Exclusions

Do not store client documents, evidence, private notes, office files, screenshots,
logs, result bundles, credentials, local settings, caches, builds, dependencies,
training, podcasts, simulations, handovers, review transcripts, or raw scan output.
