# Documentation Inventory

## Controlled Destinations

- `README.md` links controlled documents and local use.
- `CONTEXT.md` defines controlled domain terms.
- `DEV_STATE.md` records the current controlled delivery state.
- `WORKFLOW-NOTES.md` records workflow order and common controls.
- `ACE_VISION_AND_ROADMAP.md` records product direction and gates.
- `docs/specs/` stores approved technical specifications.
- `docs/adr/` stores accepted technical decisions.
- `docs/agents/` stores agent and delivery controls.
- `docs/diagrams/controlled/mermaid/` stores editable diagram source.
- `workflows/` stores approved workflow specifications.

## Approved Sources

This documentation extracts approved technical decisions from the prior controlled workspace.
It uses domain terms, workflow decisions, agent controls, Mermaid source, and approved specifications.
It does not copy old reports.

## Excluded Sources

The migration excludes client documents, evidence, private notes, office documents,
screenshots, logs, result bundles, credentials, local environment files, caches, builds,
dependencies, training, podcasts, simulations, handovers, review transcripts, and scan output.
